# Carts

Carts and multicarts of artwork go in this folder. To add one, clone its repo
here:

```bash
cd carts
git clone https://github.com/JimWhiteheadUCSC/light-touch.git
git clone https://github.com/JimWhiteheadUCSC/open-house.git
```

Each cart becomes its own bank, alongside everything already here. New
ones appear the next time you change banks, with no restart.

To update one, run `git pull` in its folder. To remove one, delete its folder.

Pieces run in a sandbox, but they're still someone else's code, so get carts from
people you trust. To make your own, see [docs/CARTS.md](../docs/CARTS.md).
